万店调改（中改）二期
V26.9.5 · 流程 / 分配 / 体验
编
流程引擎 · 施工节点判断重构后端
优化
  • 判断规则：协作标签命中「需装修施工」，且（装修一体化公司非空 或 任一业务板块装修方式 = 第三方公司）才生成施工节点；否则跳过施工，直接流转工程预算。
  • 异常兜底：标签未命中但维护了公司、或公司均未维护且全部加盟商自装时，均不生成施工节点，避免流程误编排。
员
人员配置 · 新增「工程类型」维度PC
新增
  • 维度扩展：查询条件、列表列、添加/编辑弹窗新增「工程类型」（必填多选）；历史已配置人员默认写入现有 7 类工程类型。
  • 智能分配：项目创建后按「节点 + 工程类型 + 区域 + 品牌」自动分配人员；中改项目确认节点优先且仅从工程运维组匹配。
  • 待办调整：中改项目「项目确认」待办接收对象由工程监理调整为工程运维，项目动态记录同步变更。
物
工程物控 · 预算 / 施工 / 结算全链路PC
新增
  • 自动分配：中改项目确认后不再自动分配工程监理；工程预算创建时按「省份 + 节点 + 工程类型 + 区域 + 品牌 + 承接数」自动分配工程物控，分配失败可手动指派。
  • 全链路展示：项目、预算、施工、结算的列表 / 查询 / 详情全面补充「成控专员 / 工程物控」字段，数据全流程贯通。
  • 按钮动态化：中改结算详情【更换成控】动态化为【更换物控】，选人数据源切换工程物控池。
施
确认进场 / 施工完成 表单精简APPPC小程序
优化
  • 确认进场：表单精简为 3 项——施工日期（必填）、施工说明（0-200 字）、货架利旧（默认否）；PC 端新增提交入口。
  • 施工完成：完工表单 3 项——完工时间（必填）、完工说明（0-200 字）、完工照片 1-10 张（原「门头远景照」改为「完工照片」）；PC 端新增提交入口。

体验优化PC
优化
  • 待办修复：修复非中改项目设计退回后、重提勘场定稿选「否」时错误生成「待定稿」待办的问题。
  • 差异化展示：中改项目详情隐藏「闭店结论」、菜单隐藏「勘场信息」；设计详情处于「待确认调改清单」时自动定位「调改项清单」Tab。

V26.11.1 · 横幅 / 回访 / 设计节点
横
新增「横幅信息收集」独立事项鸣忙营造PC
新增
  • 自动触发：项目进入「施工中」即生成第三张事项卡片「横幅信息收集」；提交截止日 = 预计完工时间前 2 天，完工时间变更自动联动重算。
  • 表单与逾期：是否安装悬挂装置（必填）+ 悬挂装置长度（条件必填，米）；逾期提醒精确到分钟且不阻断填写；支持修改截止日（需填写推迟原因）。
  • 联动推送：提报保存后实时推送门店系统；「增补物料提报」新增横幅信息修改入口，再次提报覆盖更新。
访
开业回访问卷新增「监理关键节点跟进」题筹建事项H5PC
新增
  • 新增第 10 题：「集团工程中心的监理是否完成 3 次（勘场、中途、验收）关键节点跟进？」必答是非题，问题反馈顺延为第 11 题。
  • 条件交互：选「否」须勾选未完成节点（勘场 / 中途 / 验收），可补充说明（200 字内）。
  • 列表导出：加盟商回访列表与导出新增「监理节点跟进」列，固定插在「问题反馈」列之前。

上传下单图与编辑门店合并统一门户工程PC
优化

03
酷家乐同步设备外形尺寸取值优化
V2.2.1 · 含历史数据修复
设
设备信息实时取商品档案值PC
优化
  • 实时查询：门店编辑、设计详情、项目详情及项目列表 / 设计列表导出，设备商品属性（名称、分类、单位、规格型号、产地、品牌、外形尺寸）按商品 ID 实时查询商品档案；档案维护后无需任何同步操作即时生效。
  • 历史数据修复：存量被酷家乐返回值覆盖的错误数据自动失效，无需历史刷数；匹配不到档案（未分类明细）时以落库值兜底展示。
  • 字段范围：仅商品属性字段改取值口径；设备数量等门店侧维护字段、门店货架不受影响。
接
下游门店接口同步修改取值口径接口
优化
  • 口径一致：下游门店设备信息接口同样按商品 ID 实时取档案值；接口字段结构不变，仅取值口径变更，上下游同步上线，避免页面与接口出现两种口径。
