可体验的交互

  • 左侧菜单 系统设置上方新增「知识库」入口，点击打开页签
  • 资料管理：搜索/筛选、勾选批量操作、行内发布 / 下架 / 删除（弹窗确认 + Toast）
  • 视频库：上传标准视频（分类 / 关联节点 / 封面 / 可见范围）、上下架，行内「预览」可模拟播放（进度条 + 水印）
  • 上传资料：四步向导（基本信息 → 标签 → 可见范围 → 确认），提交后新资料进入列表
  • 分类 / 标签：树节点增删、标签组内添加 / 删除标签
  • 权限管理：新建权限组，选择角色与数据范围时底部实时预览命中范围
  • 已读记录：切换「图文阅读记录 / 视频播放记录」，播放视角带观看进度与完播标记；各含明细 / 按资料（视频）/ 按用户三个视角
  • 行内「预览」打开右侧文档抽屉；日历支持切换月份、点击日期
