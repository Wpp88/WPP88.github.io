原型说明（对应产品方案）

入口设计（附件2基础上新增）

  • 工作台首页：知识库 Banner + 常用应用双入口（NEW 标识）
  • 应用中心：「全部应用」网格首位置新增知识库应用
  • 「我的」页提供收藏 / 浏览记录快捷入口
  • 进入知识库为功能导航页：资料中心 / 视频学堂两大卡片入口 + 在线考试 / 课程中心 / 智能回答（建设中）
  • 资料中心 / 视频学堂均采用目录 + 标签分类视图（与 PC 用户端一致）

知识库模块能力（按附件分类体系重构）

  • 目录分类视图：门店设计 / 造价 / 施工 / 验收 / 维保 5 大篇章，二级、三级目录逐级下钻，列表内可横向切换同级分类
  • 标签分类视图：门店类型 / 门店版本 / 适用对象 / 区域 / 施工节点 5 个维度，每个标签带内容数量，点击直达资料 + 视频清单
  • 视频学堂标签快捷筛选：维度 + 标签值两级点选，与目录分类过滤叠加，可就地过滤视频并一键清除
  • 关键词查询：命中 标题、标签、分类、摘要，结果高亮并可点击热门词（含视频）
  • 在线预览：PDF / 图片 / 图文 / Excel，支持翻页与缩放提示
  • 标准视频库：目录分类过滤，在线播放（受控水印）
  • 收藏（星标实时同步「我的收藏」，资料与视频统一管理）
  • 分享：限内部（选择同事 / 复制内部链接）
  • 下载申请：填写用途提交审批，状态变为「审批中」（视频默认不可下载）

用户视角学习体验（本轮新增）

  • 未读提醒：每日 10:00 提醒未读资料，首页横幅可直达「待读资料」清单，已读自动消除
  • 继续学习：首页续播卡片展示上次进度（如已学 62%），一键续播
  • 资料 ↔ 视频互链：资料详情可跳「配套视频」，视频详情可跳「配套资料」
  • 播放器升级：续播定位、±10s 快进、点击进度条跳转、倍速播放（1.0x～2.0x）
  • 学习进度标识：列表 / 卡片展示「未读 / 已读」「学习中 x% / 已学完」
  • 搜索历史：自动记录最近搜索，支持一键清空

已读记录 / 播放记录回传

打开资料详情 / 播放视频 → 自动提示「已自动写入阅读 / 播放记录」 → 播放进度支持续播，浏览记录中展示播放进度条与学习统计 → 后台「已读记录」支持图文阅读与视频播放双维度统计（见 PC 原型）

集成方式

  • 以 H5 / 内嵌 WebView 方式嵌入现有 APP
  • 复用现有登录态与用户身份，按用户 ID 返回可见资料范围
